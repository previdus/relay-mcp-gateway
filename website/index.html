SECURITY BY BOUNDARY

Credentials should only
reach the service they belong to.

Relay keeps secret values in deployment secret stores and binds references to approved destinations. Strict egress mode checks upstream destinations and DNS answers before connecting; production deployments should also enforce network egress policy.

Read the security model ↗
01Separate agent and admin accessIndependent identities and keys protect the data and control planes.✓
02Bind credentials to destinationsUpstream tokens are sent only to their configured service.✓
03Fail closed on policy outagesRequired relationship and external policy decisions deny when unavailable.✓
04Keep request data out of telemetryAudit and trace metadata omit tool arguments, results, and credentials.✓

THREE DIFFERENT GATEWAY MODELS

Compare the approach,
then choose what fits.

There is no universal ranking for MCP gateways. These established products solve adjacent problems with different architectures. The notes below summarize their published product documentation.

ProductPrimary modelWhat it is strong atHow Relay differs
Microsoft MCP Gateway ↗Kubernetes-native tool router and control plane for MCP servers and adapters.Fits Kubernetes estates and Microsoft identity environments, including Entra ID integration.Relay is a smaller, self-hostable MCP proxy with replaceable policy, router, auth, and storage contracts.
Gravitee APIM ↗MCP proxy within a broad API management platform.Combines API plans and identity integrations with method-level MCP access policies; OAuth and dynamic client registration are documented.Relay focuses on federating existing MCP servers and composing built-in, relationship-based, and external policy checks in an open-source gateway.
KrakenD MCP Server ↗Turns configured API endpoints into MCP tools inside its API gateway.Reuses existing API gateway configuration and policies when exposing APIs to agents.Relay primarily routes and governs tools already served by MCP upstreams; it does not replace API-to-tool design for existing REST estates.

Product features and licensing can change. Verify current edition, availability, and limits with each vendor. Relay’s feature inventory and known gaps are documented in the coverage matrix.
