01 / PROTOCOL & CATALOG IMPLEMENTED · SEE COVERAGE

Expose a deliberate catalog of MCP capabilities.

Relay aggregates tool definitions from approved upstreams, namespaces physical names, and can expose stable aliases. Discovery is permission-filtered; each execution is authorized again.

Modes

  • Modern Streamable HTTP and stateless legacy requests
  • Legacy HTTP+SSE upstream adapter and trusted stdio transport
  • Optional prompts, resources, templates, completion, callbacks, notifications and Tasks V2
  • Bounded discovery, opaque pagination and optional literal catalog search

Example

{
  "features": {
    "prompts": true,
    "resources": true,
    "tasks": true
  },
  "upstreams": [{
    "id": "docs",
    "url": "https://tools.example/mcp"
  }]
}
BoundaryOptional features stay off until enabled. Legacy push callbacks aren’t bridged; Tasks V2 interoperability with independent implementations needs broader validation.

THE SECURITY QUESTION THAT MATTERS

How do you stop a secret
from going to the wrong host?

Relay supports deployment-owned bindings that connect a secret reference to the exact scheme, host, port, path and purpose allowed to receive it. In strict mode it checks the destination policy before reading a secret and validates DNS answers at connection time.

A FAIR MARKET COMPARISON

Best depends on the job.
Here’s where Relay earns a look.

These products take different approaches. Relay is a strong fit when you want an open-source MCP federation layer with customizable authorization and routing. Other gateways have advantages Relay does not claim.

  • Open-source, self-hostable core
  • Pluggable authz, routing, storage & credentials
  • OpenFGA + OPA adapters
  • Destination-bound credential safeguards
  • No built-in MCP server lifecycle deployment
  • Not production-qualified across cloud providers

OUR POSITION

Relay can be a better fit when open-source control, MCP-to-MCP federation, replaceable policies, relationship checks, and deployment flexibility are your priorities. It isn’t a substitute for Microsoft’s Kubernetes lifecycle manager, Gravitee’s full API management suite, or KrakenD’s API-to-tool conversion.
