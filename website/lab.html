    TWO DIFFERENT TLS HOPS
    mTLS identity does not teleport.
    Each TLS session has its own certificate proof. Relay terminates the agent connection, then presents a distinct gateway client certificate to the protected MCP server.
    01 Verify agent cert02 Enforce identity policy03 Present upstream cert
    The hosted demo does not ask visitors for certificates. Use the local mTLS integration tests and outbound TLS setup guide to validate a real certificate pair.
